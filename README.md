# CodeWithMe Repository

## About This Repository

This is a learning repository created by **Auroria Digital Forge** that contains various programming examples, demonstrations, and documentation.

## Contents

### Web Projects
- **index.html** - An animated birthday greeting card with interactive elements
  - Features balloons, cakes, fireworks, and heart animations
  - Interactive envelope with a personalized birthday message
  - Created using HTML5, CSS3, and vanilla JavaScript

### Programming Examples
- **First C program** - Introduction to C programming
- **Recursion in python** - Python recursion examples and explanations

### Documentation
- **SESSION_SWITCH_EXPLANATION.md** - Comprehensive explanation of the `session-switch.mjs` file from the [different-ai/openwork](https://github.com/different-ai/openwork) repository
  - Details about OpenWork's session management testing
  - Test flow and architecture documentation
  - Integration testing best practices

### Assets
- Various PNG images used in the birthday card project (balloons, cakes, fireworks, etc.)

## Projects Overview

### Birthday Greeting Card
An interactive web-based birthday card with:
- Smooth animations using CSS keyframes
- Mouse tracking heart effects
- Interactive envelope opening
- Personalized birthday message
- Mobile-responsive design
- Beautiful gradient backgrounds and visual effects

**Technology Stack:**
- HTML5
- CSS3 (with advanced animations)
- Vanilla JavaScript
- Font Awesome icons
- Google Fonts
